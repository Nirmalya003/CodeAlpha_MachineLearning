## 📌 Projects

### 1. Credit Scoring Model

**Folder:** `Task-1-Credit-Scoring`

This project focuses on building a Machine Learning model for assessing credit risk based on financial and customer-related information.

The project demonstrates how classification algorithms can be used to predict whether a customer represents a higher or lower credit risk.

#### Key Steps

1. Data loading
2. Data exploration
3. Data cleaning
4. Data preprocessing
5. Feature preparation
6. Model training
7. Model prediction
8. Model evaluation
9. Performance analysis

#### Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1-Score
- ROC-AUC

### 2. Handwritten Character Recognition

**Folder:** `Task-3-Handwritten-Character-Recognition`

This project focuses on recognizing handwritten characters using image-processing and Machine Learning techniques.

The model learns patterns from handwritten character images and predicts the corresponding character class.

#### Key Steps

1. Dataset loading
2. Image preprocessing
3. Data normalization
4. Feature preparation
5. Model training
6. Character prediction
7. Model evaluation

#### Concepts Covered

- Image processing
- Classification

- Model training

- Accuracy evaluation
